# C Mini Interpreter


## Özellikler

- Değişken tanımlama
- Değişkenleri görüntüleme
- İşlemleri hesaplama
- İşlem sonuçlarını dosyaya kaydetme
- Kayıtlı değişkenleri dosyadan yükleme
- Menü tabanlı komut sistemi

## Kullanılan Konular

- Struct ve typedef
- Diziler
- Dosya işlemleri
- Fonksiyonlar
- Switch-case
- Döngüler
- String işlemleri
- Hata kontrolü
